# Orange Note v4.2.0 更新说明

本次更新修复 Orange Note 与 BrowserSkill 0.4 的连接兼容问题，并改进符号链接文件下载。

## 主要更新

- 适配 BrowserSkill 0.4 的共享控制：页面操作前同步状态，每次操作使用新的单次上下文；首次进入 Agent 自有空白页保留原有导航流程。
- 保留已验证的 BrowserSkill 0.3 调用路径；无法确定 CLI 版本时停止操作并报告原因。
- 页面控制暂不可用时不执行或自动重放操作；启动与深度诊断显示实际协作错误，避免误报成工作区启动超时。
- 当服务端的 Content-Range 显示目标大小与文件元数据不同，使用专属 kernel 验证符号链接及目标文件的身份和变更信息，支持正常大小及空文件下载。
- 保留独立会话、任务回执、幂等键和已有文件保护规则。后台任务状态仍通过原 job ID 查询。

## 验证情况

- Windows Python：178 项测试中 177 项通过、1 项 POSIX 专用测试跳过；Node：13 项通过。
- BrowserSkill 0.4、Edge 和真实工作区：连接、两个独立会话和 kernel、文件上传下载、符号链接下载，以及短后台任务和重复幂等键均通过测试。
- BrowserSkill 0.3 的本次验证为模拟测试；实时 0.3、长时间高负载、真实网络中断和人工接管场景尚未实测。

符号链接修正需要服务端提供可比较的 Content-Range 大小；某些服务器或链接与目标恰好同大小时不保证触发修正。默认 SHA-256 覆盖不超过 64 MiB 的文件，更大文件仅进行大小级验证。完整范围见 [验证记录](VALIDATION_v4.2.0.md)。

升级前应等待当前 Agent 操作结束。安装新版不会主动迁移或删除现有会话配置和后台任务回执。
